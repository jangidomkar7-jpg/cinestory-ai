How CineStory works

1. Write a story and create a storyboard. 2. Select each scene and add a photo or generated image. 3. Preview the sequence, then export MP4.

Honest limitation: this starter version automatically creates scene breakdowns and cinematic prompts, but does not generate realistic AI images or moving AI footage by itself. Add your own images for each scene. Connecting a real image/video generation provider requires its API and a secure backend.

MP4 conversion uses FFmpeg.wasm downloaded from a CDN. The exported video includes visuals and optional background music. Browser text-to-speech is for preview and is not embedded in the exported file.
